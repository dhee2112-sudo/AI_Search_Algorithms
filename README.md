 Search Algorithms

 Overview
This project implements search algorithms used in AI for pathfinding.

 Algorithms Implemented
1. Dijkstra Algorithm
- Finds shortest path with different costs
2. A* Algorithm
- Uses heuristic (Manhattan distance)
- Faster than Dijkstra
3. Dynamic A*
- Handles dynamic obstacles
- Replans path in real-time
## Problem Statements
1. Road Network
- Shortest path using Dijkstra
2. UGV Navigation (Static)
- Grid pathfinding avoiding obstacles
3. UGV Navigation (Dynamic)
- Obstacles appear randomly
- Agent recalculates path
## Conclusion
- Dijkstra is optimal but slow  
- A* is faster using heuristic  
- Dynamic A* works in real environments
